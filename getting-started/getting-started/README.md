# Getting Started

## Account Creation and Onboarding

You begin by signing up for AetherFlow to access the dashboard. The platform guides you through a quick onboarding process, explaining core concepts like prompts and triggers. This ensures you understand how natural language drives automations without technical barriers.

> Use your work email for team collaboration features from the start.

## Installation and access

AetherFlow is available through the dashboard. You do not need a local installation.

1. Create your account with your work email.
2. Complete the onboarding prompts.
3. Open the dashboard and create your first workflow.

Keep the dashboard bookmarked for quick access. Invite collaborators after your workflow has a clear owner.

## Best practices

Start with one small, repeatable task. This makes each workflow easier to validate and improve.

* Write prompts with a clear goal and expected result.
* Choose triggers that run only when needed.
* Test each workflow with realistic inputs before sharing it.

Review active workflows regularly. Update prompts when the underlying process changes.

Assign an owner to every shared workflow. The owner should maintain its prompts and triggers.
